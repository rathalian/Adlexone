The work

An application is a line of work.

People open an application and work the records. An administrator decides the record type, the fields, the screens, and the rules. Every application uses the same people, the same fields, and the same records store.

Prepared applications

Create an application starts from one of these. You can change the fields and the screens after that. Blank has no fields yet.

  • Publishing

    A manuscript from the day it arrives until it is approved or declined.

  • Client matters

    A matter from the instruction until it is done.

  • Conveyancing

    A sale or a purchase, from instruction to completion.

  • Insurance claims

    An insurance claim from the first notification until it is settled or withdrawn.

  • Repairs

    A repair from the report until it is done.

  • Complaints

    A complaint from the day it is opened until it is upheld or not upheld.

  • Committee papers

    A paper from the day it arrives until it is awarded or refused.

  • Audit findings

    A finding from the day it is raised until it is closed.

  • Incidents

    An incident from the report until it is closed.

  • Recruitment

    A candidate from the first approach until they are placed or withdrawn.

  • Contracts

    A contract from the day it arrives until it is signed or declined.

  • Blank

    An empty application and one record type. Add fields when you are ready.

Screens on an application

You choose the screens when you create the application, and you can change them later. These are the screens the software already has.

  • Work

    The list of records, as a list or a board.

  • New

    Add a record.

  • Search

    Search every field. A search you save is listed on Saved.

  • Counts

    How many records are in each status.

  • Owners

    Who has the work. Records with no owner are listed first.

  • Next steps

    The next action on an open record. Finished records stay off this list.

  • Diary

    Open records grouped by a date, such as Reply due.

  • Parties

    Records grouped by a name, such as the writer or the client.

  • Activity

    Recent log lines.

  • Files

    Files added to the records.

  • Ageing

    How long open records have been open.

  • Register

    One row per record.

  • Intake

    A short form that adds a record.

  • Saved

    Searches a person has saved.

  • Announcements

    A notice on the application.

  • Settings

    How this application is set up.

Fields and record types

A record type sets the fields a record uses. Fields are shared across the applications, so a field you add once can appear on more than one record type.

A field can be text, a note, a menu, a checkbox, a date, a time, a date and time, an email address, a number, a link, or a person. Publishing uses this for a manuscript: status, writer, kind, word count, next step, a note, and the dates the work moves through.

Rules

Each application runs its own rules. A rule is when something happens, a test on a field, then one or more actions in order.

It runs when a record is created, when a record is updated, when a log line is added, or when a file is attached. The test can be that a field equals a value, becomes a value, changes, is empty, or contains some text. The action can send an email, write a log line, set a field, set the owner, stamp today’s date, or post a notice.

Approve the manuscript

When Status becomes Approved, Publishing does this, in order.

  1. Stamp Approved on with today’s date.
  2. Write a log line: Approved Home to Roost for publication.
  3. Post a notice, and send an email, to say Home to Roost has been approved for publication.
  4. Clear Next step.

The same pattern is already set on the other prepared applications. A repair emails the owner when someone is on site. A complaint posts a notice when it is upheld. You can change a rule, or add one, without changing the screens.

People and groups

A person is someone who can sign in. Add a person when they need access. A group is the set of people who share a record. A rule can write to the owner, the creator, a person, a group, or an address you name.
