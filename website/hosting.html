The server

You run it on your server.

Adlexone is the software. The database, the settings, and the uploaded files stay on the server you choose. A browser must not be able to download them by guessing an address.

One site

Open the site when it has no administrator. Setup has three steps.

  1. Confirm the document root. On shared hosting, point the domain at the public folder. If the host cannot change the document root, the install folder itself can be the document root.
  2. Choose the storage directory. Adlexone creates the settings, the database, and the attachments folder there, and checks that PHP can write them. A folder inside the website is refused when a browser can read it.
  3. Set the name shown on the sign-in page. It can be the organisation, such as Health. Then create the first administrator.

Several customer sites

The host installer is a different page. It turns one copy into a host of customer sites. A customer finishing setup on their own hostname is not this page.

  1. Confirm the document root, and choose a stores directory outside the website. For example, a folder the account owns. Setup checks that PHP can write there, and that a browser cannot read it.
  2. Set the operator hostname, such as operate.example.com. It must not be a customer hostname.
  3. Create the operator account on that hostname. The operator is a separate login. It is not a user inside a customer site.

What one customer has

Each customer gets one folder. For example, Health, at health.example.com. The folder holds the database, the settings, and the uploaded files. One request opens one database. Leave the administrator password blank and their first visit is setup, on their own paths.

The operator can change the display name, the hostname, and the contact email. The folder name stays as it is. Measure usage reads the folder and stores the figures. The rate is a monthly amount, an amount per person, and an amount per gigabyte of that folder. There is no invoice.

Suspend stops sign-in and leaves every file in place. Resume turns the site back on. Backup downloads the database, the settings, and the files. Delete removes the folder after you type its name. Delete is permanent.

Sign-in, email, and the theme

A person signs in with a local account. OpenID Connect can be added when you want sign-in to come from an identity service you already run. Mail leaves through the SMTP settings an administrator saves. A password field left blank keeps the current value.

The site has one colour, set by its theme. The first application uses that colour. A person can choose another theme on their own account.

What the server needs

  • PHP 8.1 or later, with the pdo_sqlite, dom, libxml, and xml extensions.
  • SQLite. The database file sits in the storage directory, off the public folder.
  • A server that sends requests to index.php. Apache with mod_rewrite is the path when the install folder is the document root.

To update, unzip the next release over the same folder. The settings and the database stay where they are, and the database is brought up to date on the next request.
