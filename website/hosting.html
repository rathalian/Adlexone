You run it on your server.

The database, the settings, and the uploaded files stay in a folder a browser cannot open.

One site

  1. Confirm the document root.
  2. Choose a storage directory a browser cannot read.
  3. Create the first administrator. The sign-in name can be Health.

Several customer sites

  1. Choose a stores directory outside the website.
  2. Set the operator hostname, such as operate.example.com.
  3. Create the operator account. It is not a user inside a customer site.

What the server needs

PHP 8.1 with SQLite, and a storage folder off the public folder.
