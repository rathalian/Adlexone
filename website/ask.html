A copy

Ask for a copy of Adlexone.

A copy is a release zip of the software. You unzip it on your server and open the site. When the database is empty, setup runs. The zip does not contain a database, settings, or this website.

Write to info@oneorzero.com

What to include

  1. The organisation. For example, Health.
  2. The hostname people will use. For example, health.example.com. A host also names the operator hostname, such as operate.example.com.
  3. Whether you want one site, or one copy that hosts several customers.
  4. The name of the first administrator.

Use the subject “A copy of Adlexone”. Licensing questions go to the same address.

The licence

The licence in the software is the Adlexone FlowIQ Licence. You may modify your copy. A file that carries the licence header keeps that header. Copying Adlexone and distributing it as your own software needs written permission from Adlexone.

There is no warranty for the data the software holds, for the configuration, or for the hosting. There is no warranty for a copy that someone other than Adlexone has modified, unless that has been agreed.
